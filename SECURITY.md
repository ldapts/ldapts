# Security Policy

## Supported versions

Security fixes are released for the latest major version of ldapts. Upgrade to the latest release to receive them.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/ldapts/ldapts/security/advisories/new).
Include the affected versions, a description of the issue, and steps or a proof of concept to reproduce it.

You can expect an acknowledgement within a few days. Once a fix is released, the advisory is published with credit to the reporter unless they ask otherwise.
